If Clause — Type 0, 1, 2, 3
Conditional sentences "যদি...তাহলে" ধরনের বাক্য — কোনো শর্ত (condition) দেওয়া হয় এবং তার পরিণতি (result) বলা হয়। English-এ মূলত চার ধরনের conditional আছে। এগুলো সঠিকভাবে ব্যবহার করতে পারলে আপনার ভাষা অনেক sophisticated হয়।
0️⃣ Zero Conditional — সর্বদা সত্য
Formula
If + Present Simple, + Present Simple

সাধারণ সত্য বা বৈজ্ঞানিক তথ্য বোঝাতে ব্যবহার হয় — যা সবসময় সত্য।

If you heat water to 100°C, it boils.
যদি পানি ১০০°C-এ গরম করো, এটা ফুটবে।
If it rains, the ground gets wet.
যদি বৃষ্টি হয়, মাটি ভেজে।
1️⃣ First Conditional — সম্ভব ভবিষ্যৎ
Formula
If + Present Simple, + will + V1

বাস্তবে সম্ভব এমন ভবিষ্যৎ পরিস্থিতি বোঝাতে — যা হতে পারে।

If you study hard, you will pass the exam.
যদি ভালো পড়ো, পরীক্ষায় পাস করবে।
If it rains tomorrow, we won't go out.
যদি কাল বৃষ্টি হয়, আমরা বাইরে যাব না।
2️⃣ Second Conditional — অবাস্তব বর্তমান
Formula
If + Past Simple, + would + V1

বর্তমানে অবাস্তব বা কল্পনাপ্রসূত পরিস্থিতি বোঝাতে — আসলে এটা হচ্ছে না।

If I had a million dollars, I would travel the world.
যদি আমার কাছে এক মিলিয়ন ডলার থাকত, আমি পৃথিবী ঘুরতাম।
If she were taller, she could be a model.
যদি সে লম্বা হত, মডেল হতে পারত।
💡
মনে রাখুন: Second conditional-এ "I/he/she/it"-এর সাথেও "was"-এর বদলে formal English-এ were ব্যবহার হয় — "If I were you..."
3️⃣ Third Conditional — অতীতের অবাস্তব
Formula
If + Past Perfect, + would have + V3

অতীতে যা হয়নি কিন্তু হলে কী হত — অনুশোচনা বা কল্পনা বোঝাতে।

If I had studied harder, I would have passed.
যদি আরও ভালো পড়তাম, পাস করতাম। (কিন্তু পড়িনি, তাই পাস হয়নি।)
If she had come earlier, she would have met him.
যদি সে আগে আসত, তার সাথে দেখা হত।

📝 Practice Quiz
1. If you touch fire, it ___ you. (সর্বদা সত্য — Zero)
burns
will burn
would burn
✅ ঠিক! Zero Conditional-এ উভয় clause-এ Present Simple।
2. If it rains tomorrow, I ___ stay home. (সম্ভব ভবিষ্যৎ)
would
will
stayed
✅ সঠিক! First Conditional: If + Present, will + V1।
3. If I ___ a bird, I would fly everywhere. (অবাস্তব কল্পনা)
were
am
will be
✅ ঠিক! Second Conditional-এ "If I were..." ব্যবহার হয়।
4. If she had studied, she ___ passed. (অতীতের অনুশোচনা)
would pass
would have passed
will have passed
✅ সঠিক! Third Conditional: would have + V3।
5. "If I were the president, I would build more schools." — এটি কোন conditional?
First
Second
Third
✅ ঠিক! Past Simple + would + V1 = Second Conditional (অবাস্তব কল্পনা)।
