Active থেকে Passive বানানো
Active Voice-এ subject নিজে কাজটি করে (যেমন: "I wrote a letter")। Passive Voice-এ object-কে subject বানিয়ে কাজটি কার উপর ঘটেছে তার উপর জোর দেওয়া হয় (যেমন: "A letter was written by me")। সংবাদ, রিপোর্ট এবং formal লেখায় passive voice খুব বেশি ব্যবহৃত হয়।
🧩 Active vs Passive Formula
Active Voice
Subject + Verb + Object
Rahim wrote a letter.
Passive Voice
Object + am/is/are/was/were + Verb(V3) + by + Subject
A letter was written by Rahim.
🔁 রূপান্তরের নিয়ম (Step by Step)
  1. Object-কে নতুন বাক্যের শুরুতে নিয়ে আসুন (নতুন subject)।
  2. Tense অনুযায়ী "be" verb (is/am/are/was/were/has been...) যুক্ত করুন।
  3. Main verb-কে V3 (past participle)-এ পরিবর্তন করুন।
  4. মূল subject-এর আগে "by" যুক্ত করুন (প্রয়োজন না হলে বাদ দেওয়া যায়)।
💡
উদাহরণ: "She cooks rice." → Object "rice" সামনে আনুন → "Rice is cooked by her."
📋 Tense অনুযায়ী Passive Form
TenseActivePassive
Present SimpleHe cleans the room.The room is cleaned (by him).
Past SimpleShe wrote the letter.The letter was written (by her).
Future SimpleThey will build a house.A house will be built (by them).
Present PerfectI have finished the work.The work has been finished.
Present ContinuousShe is making tea.Tea is being made (by her).
📘 কখন Passive Voice ব্যবহার হয়
English is spoken all over the world.
কাজটি কে করছে তা গুরুত্বপূর্ণ নয়, ফলাফল গুরুত্বপূর্ণ।
The window was broken (by someone).
কে করেছে জানা নেই বা গুরুত্বপূর্ণ নয়।
The bridge was built in 1990.
Formal/factual লেখায় (সংবাদ, রিপোর্ট, ইতিহাস)।
⚠️
মনে রাখুন: "by + agent" অংশটি অনেক সময় বাদ দেওয়া হয়, যদি কে করেছে তা গুরুত্বপূর্ণ না হয় বা পরিচিত হয়।
📝 Practice Quiz
1. "Tom eats an apple." — Passive form কী হবে?
An apple is eaten by Tom.
An apple eats by Tom.
An apple was eaten Tom.
✅ ঠিক! Present Simple Passive: Object + is/am/are + V3।
2. "She wrote a story." — Passive form কী হবে?
A story is written by her.
A story was written by her.
A story writes by her.
✅ সঠিক! Past Simple Passive: Object + was/were + V3।
3. "They will build a school." — Passive form কী হবে?
A school will be built by them.
A school will built by them.
A school is built by them.
✅ ঠিক! Future Passive: Object + will be + V3।
4. "English is spoken all over the world." — এখানে "by" উহ্য (omitted) কেন?
কারণ কে বলে তা স্পষ্ট/গুরুত্বহীন
কারণ এটি ভুল বাক্য
কারণ এটি Active voice
✅ ঠিক! সাধারণ সত্য বা স্পষ্ট agent থাকলে "by" বাদ দেওয়া হয়।
